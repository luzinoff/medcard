# Медкарта

Личная медицинская карта в одном HTML-файле: анализы с динамикой, инфекции и посевы с антибиотикограммой, инструментальные исследования, лечение, донорство, архив документов, планы контроля.

Открыть: https://luzinoff.github.io/medcard/

- **Данных в репозитории нет.** Все записи лежат в браузере и в скрытой папке приложения на Google Диске владельца (`medcard.json`, доступ `drive.appdata`).
- **Документы** (PDF, фото бланков) разбирает Gemini. Перед добавлением в карту показывается предпросмотр.
- **Дневник** (`luzinoff.github.io/dnevnik`) открывается с того же адреса, поэтому медкарта сама берёт его настройки (Client ID, ключ и модель Gemini) и данные (вес, пульс, сон, шаги, тренировки, добавки). Дневник при этом только читается.
- **Несколько человек.** Кнопка 👥 в шапке: можно завести отдельную чистую карту для члена семьи (та же структура, без данных дневника). Каждая карта синхронизируется в свой файл (`medcard-<id>.json`) в той же скрытой папке Диска; при запуске открывается карта владельца.

## Общие настройки с дневником и медкартой (14.11.2026)

Бюджет, дневник и медкарта открываются с одного сайта `luzinoff.github.io`
и видят одну память браузера. Client ID Google и ключ с моделью Gemini
лежат ещё и в общей записи `luz.shared.v1`: ввёл или поменял в любом из
трёх приложений — остальные подхватили, даже открытые в соседней вкладке
(событие `storage`). Блок `luzShared` одинаковый во всех трёх файлах;
у каждого приложения свой переходник к своим настройкам (в медкарте —
`luzMedOwn()`/`luzMedApply()` над `settings.clientId`, `geminiKey`,
`geminiModel`). При запуске общее побеждает; поля, которых в общем
ещё нет, заполняются своими. В общее при сохранении уходит только то, что поменяли
в этой вкладке, — иначе вкладка со старыми значениями затёрла бы свежие.
Удаление ключа тоже общее.
